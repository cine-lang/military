# 신병 더 무비 — 군병원 체험

영화 '신병 더 무비: 군병원에 귀신이 산다'(12월 30일 개봉) 연계 군병원 괴담 체험 사이트.

- 사이트: https://cine-lang.github.io/military/
- 여러 명이 같은 병실에 함께 보이는 실시간 기능은 공개 MQTT 중계 서버(EMQX, HiveMQ 공개 브로커)를 씁니다. 계정 없이 무료로 쓸 수 있지만 운영 보증이 없으므로, 정식 오픈 전에는 관리형 실시간 서비스로 바꾸는 것을 권장합니다. 설정은 `index.html`의 `window.SINBYEONG_MQTT`.
